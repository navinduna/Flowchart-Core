# Flowchart Core - Advanced Web Flowchart Engine

Flowchart Core is a high-fidelity, interactive flowchart design and execution engine built purely using modern web technologies. It allows users to visually architect algorithms, write live logic inside geometric structures, and evaluate processes natively within the browser environment.


## 🚀 Key Features

- **Live Logical Evaluation Subsystem:** Natively parses and runs visual algorithms (Inputs, Processes, Decisions, Prints) directly through a dedicated browser runtime trace log.
- **Dynamic Adaptable Themes:** Complete context-aware Dark and Light Mode toggle that intelligently transitions nodes, layouts, and vector connection colors.
- **Smart Orthogonal Vector Routing:** Custom Manhattan geometry routing logic for connection lines to ensure strict alignment with a 20px grid matrix.
- **Automated Registry Cache:** Real-time persistence using `localStorage` ensures users never lose their active workspace state upon page reloads.
- **Robust Multi-Workspace Architecture:** Supports dynamic tab creation, smooth canvas panning, pinch-to-zoom gestures, and regional marquee group selections.
- **Production-Grade Exports:** Seamlessly download architectural layouts in multiple file formats, including high-density **PNG, JPEG, JPG, and PDF** via clean HTML canvas projection.
- **Non-Linear History Pipeline:** Advanced memory tracking setup supporting precise `Undo` and `Redo` action stacks up to 50 iterations deep.

---

## 🛠️ Built With

- **Core Architecture:** Vanilla HTML5, JavaScript (ES6+)
- **Styling Pipeline:** Tailwind CSS (Highly optimized layout & responsive grid rules)
- **Vector Graphics:** Native SVG (High-fidelity line anchors and rendering)
- **Icons Representation:** Lucide Icons Subsystem
- **Render Generators:** `html2canvas` for matrix canvas screenshot maps & `jsPDF` for legal document printing pipeline.
