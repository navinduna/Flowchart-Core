Read Guideline (භාවිත කරන්නේ කෙසේද?)

වැදගත්:

මෙම Flowchart Engine එක සජීවීව ක්‍රියාත්මක කළ හැකිය (Live Evaluation). එබැවින් හැඩතල තුල විධානයන් ලිවීමේදී පහත නීති රීති අනිවාර්යයෙන්ම පිළිපදින්න.

1. Variables (විචල්‍යයන් භාවිතය)

ඔබට අවශ්‍ය ඕනෑම නමකින් විචල්‍යයක් தනි වචනයෙන් සාදාගත හැක (උදා: x, total, marks). විචල්‍යයන් Case-Sensitive වේ.

2. Input Box (දත්ත ඇතුළත් කිරීම)

  • තනි Input එකක් ගැනීමට: විචල්යයේ නම ලියන්න (උදා: x).
  • එකවර Input කිහිපයක් ගැනීමට: විචල්යයන් එකිනෙක නව පේළිවල (Enter ඔබා) ලියන්න.
    උදා:
    x : "Enter X"
         y : "Enter Y"

Custom Input Prompts (පරිශීලක ආදාන)

Input Container එක තුල Variable එක සමඟ ඔබට පෙන්වීමට අවශ්‍ය පණිවිඩය variable_name : "පණිවිඩය" ලෙස ලබා දෙන්න. (උදා: num : "Enter your number")

3. Process Box (ගණනය කිරීම් සහ අගයන් පැවරීම්)

ගණනය කිරීම් කිහිපයක් එකවර කිරීමට: විධානයන් එකිනෙක නව පේළිවලින් (Enter ඔබා) හෝ සෙමිකෝලන ( ; ) මගින් වෙන් කර ලියන්න.
උදා:
x = 10
y = x + 5

4. Decision Box (තීරණ ගැනීම / If Condition)

සංසන්දනය කිරීමට අවශ්‍ය කොන්දේසිය පමණක් ඇතුළත් කරන්න. ==, >=, <=, != භාවිත කරන්න.

⚠️ මතක තබාගන්න: Decision කොටුවෙන් එළියට ඊතල දෙකක් අඳින්න. ඉන්පසු එම ඊතල (Lines) මත Click කර, එකක් True ලෙසද අනෙක False ලෙසද Node Properties มගින් නිවැරදිව ලේබල් කරන්න.

5. Print / Display Box (ප්රතිදානයන් පෙන්වීම)

  • එකම පේළියක Text සහ විචල්ය පෙන්වීමට: අගයන් කොමාවලින් වෙන්කර ලියන්න (උදා: "Total is", total).
  • එකවර පේළි කිහිපයක් ප්රින්ට් කිරීමට: ප්රතිදාන විධානයන් Enter ඔබා අලුත් පේළිවල වෙන වෙනම ලියන්න.
    උදා:
    "X value is", x
    "Y value is", y

6. Mobile / Touch Controls (මොබයිල් සහ ස්පර්ශක භාවිතය)

ජංගම දුරකථන සහ ටැබ්ලට් මගින් භාවිත කරද්දී:

  • හැඩතල චලනය කිරීම (Move Shapes): හැඩතලයක් මත ඇඟිල්ල තබා අවශ්‍ය තැනට ඇදගෙන යන්න.
  • ඊතල ඇඳීම (Line Drawing): හැඩතලයේ දාරයක ඇති කුඩා තිතක් (Port) මතින් ස්පර්ශය ආරම්භ කර, ඇඟිල්ල ඉවතට නොගෙන අනෙක් හැඩතලයේ තිතක් මතට ඇදගෙන ගොස් අතහරින්න.
  • රේඛා වෙනස් කිරීම (Line Adjustments): ඕනෑම ඊතලයක් මත එක පාරක් ස්පර්ශ කිරීමෙන් එහි මැද හෝ කෙළවර හැඬල් (Blue and White Circles) මතුවන අතර, ඒවා ඇදගෙන යාමෙන් ඊතල ගැලවීම හෝ නැමීම කළ හැක.
  • Workspace Tabs: Tab එකක් Rename කිරීමට එහි නම මත Double-Tap කරන්න.
  • Properties Panel එක විවෘත කිරීම: මොබයිල් හෝ ටැබ්ලට්වලදී හැඩතලයක් මත එක දිගට දෙපාරක් ස්පර්ශ (Double-Tap) කරන්න. (පරිගණකයේදී සාමාන්ය පරිදි එක ක්ලික් එකකින් විවෘත වේ).

7. Advanced Selection Shortcuts (සමූහ සහ ප්‍රදේශ තෝරාගැනීම්)

  • Shift + Drag Selector Area: Shift කී එක ඔබාගෙන Canvas එකෙහි හිස් තැනක සිට මවුසය ඇදගෙන යාමෙන් (Marquee Area Box) එකවර හැඩතල කිහිපයක් එකට තෝරාගත හැක.
  • Shift + Click Selection Additive: Shift කී එක ඔබාගෙන හැඩතල මත ක්ලික් කිරීමෙන් පවතින සමූහයට නව හැඩතල එකින් එක එක්කර ගැනීමට හෝ ඉවත් කිරීමට හැකිය.
  • Group Dragging: එකවර හැඩතල කිහිපයක් තෝරාගෙන ඇති විට, ඕනෑම එකක් මවුසයෙන් ඇදගෙන යාමෙන් මුළු සමූහයම එකවර Lecture කර චලනය කළ හැකිය.
